# parametric-shelf

An open-frame shelf printed as a single piece. Two hex-lattice side walls + solid top, unioned into one continuous solid. Fully customizable via the WASM customizer.

## File layout

```
lib/
  parametric-shelf-lib.scad    all params + geometry modules, no top-level render
parts/
  shelf.scad                   include + $fn + shelf()   → shelf.stl
```

There is **no `previews/` directory** and no multicolor 3MF — the shelf is a single-color, single-piece part, so a multicolor preview would just duplicate the STL. The gallery viewer renders `shelf.stl` directly.

## Public modules

- **`shelf()`** — the whole shelf as one piece. Positive octant: `X=[0,width], Y=[0,depth], Z=[0,height]`. Composes two mirrored side walls with the top plate. This is the only public entry point.

Internal helpers (leading underscore — not stable API):

- **`_side_wall()`** — one side wall, laid flat with gusset fins standing perpendicular. Called twice inside `shelf()`; the right invocation is wrapped in `translate([width,0,0]) mirror([1,0,0])` so its gussets face inward.
- **`_gusset_fin(x_start)`** — a single triangular gusset fin.
- **`_hex_grid(...)`** / **`_hex_prism(...)`** — the hex-lattice cutter grid.

## Print orientation

The STL is emitted in "as-installed" orientation (bottom of side walls at Z=0, top plate up). The natural print orientation is upside-down: rotate 180° in the slicer so the top plate lies on the bed. Then:

- Top plate is a flat first layer (no supports).
- Side walls print vertically upward — the hex through-holes are short horizontal bridges (only `wall_thickness` = 5 mm long by default), which slice cleanly without support.
- Gussets end up on the bed as small triangular fins, printed alongside the top plate.

Nothing in the lib assumes a particular print orientation, so users can also print it right-side-up or on its side — but the upside-down orientation is by far the cleanest.

## Hex lattice

Pointy-top honeycomb, filling only the interior "window" of the side wall — the perimeter frame (`column_size` = 12 mm wide) stays solid so the corner columns are unbroken. `_hex_grid(w, h, cut_depth, s, wall)`:

- `pitch_x = s + wall` (horizontal center-to-center within a row)
- `pitch_y = (s + wall) * sqrt(3) / 2` (row-to-row vertical center-to-center)
- Alternate rows shift by `pitch_x / 2` (standard triangular offset)

The grid is over-generated by one ring and clipped with `intersection()` to the interior-window box, so hexes at the frame edge truncate cleanly instead of leaving partial cells that punch through the column.

## Gussets

Four right-triangle braces at the internal top corners (two per side wall, one at the front edge and one at the back). Baked into `_side_wall()` so they print as part of the single STL. `gusset_length` sets both leg lengths; set it to 0 to disable them entirely (the `union()` in `_side_wall()` guards on that).

Because the same `_side_wall()` invocation is used for both walls, the right wall is mirrored at placement time so its gussets face inward. If you ever split the walls back into two distinct modules, drop the mirror.

## Editing rules

- **Don't** redefine any of the customizable params (`hex_size`, `height`, `width`, `depth`, `top_thickness`, `wall_thickness`, `gusset_length`) in consumers — the lib owns them.
- **Don't** add top-level geometry in `parts/shelf.scad`. Keep it three lines.
- **Don't** drop the `mirror([1,0,0])` on the right wall inside `shelf()` — both walls' gussets need to face inward, and both come from the same `_side_wall()`.
- If you later split the shelf into multiple STLs (e.g. sides separate from top for wider beds), you'll also need to add a `previews/` directory + preview import + `CUSTOMIZABLE_SOURCES["parametric-shelf"].previews` entry to re-enable an assembly preview.
