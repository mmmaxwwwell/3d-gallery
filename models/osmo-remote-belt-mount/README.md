# Osmo Remote Belt Mount

Belt-mount cradle for the [YDW Bluetooth Remote Control for DJI Osmo Action cameras](https://www.amazon.com/dp/B0GF1RWSR2). Holds the remote against a belt via a rear belt-loop slot so the shutter/record button stays reachable one-handed.

## Print

- PLA or PETG, 3 walls, 20% infill.
- No supports (belt slot is horizontal, cradle opens upward).

## Hardware

- 1× YDW Bluetooth remote (Amazon B0GF1RWSR2)
- Belt (worn through the rear slot)

## Status

Scaffold only — geometry is a placeholder cuboid pocket. Measured dimensions and cradle/belt-loop features still to be added.
