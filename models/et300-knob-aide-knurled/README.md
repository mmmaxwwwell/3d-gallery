# Educator ET-300 Knob Aide — Knurled

A 17.3 mm-tall cap that slips over the intensity knob of the Educator Mini ET-300 remote and gives a bigger, grippier turning surface. The rim is a diamond-knurled pattern — raised diamond bumps in a staggered lattice — like a traditional knurled knob. Top and bottom outer edges are filleted so nothing catches on skin or fabric.

Interior of the cap:

- 1 mm solid top cap over the "circle + plus" key so the whole thing pushes down flush against the top of the knob.
- Circle + plus keying cutout down through most of the cap so the aide can't spin on the knob shaft.
- 15 mm ⌀ × 4.8 mm cylindrical pocket at the bottom that clears the base of the knob.

## Parameters (customizable)

| Param                    | Meaning                                                        | Default |
|--------------------------|----------------------------------------------------------------|---------|
| `outer_diameter`         | Diamond-bump-tip outer diameter (mm)                           | 26      |
| `thickness`              | Overall cap height (mm)                                        | 17.3    |
| `top_cap_thickness`      | Solid material above the "circle + plus" cutout (mm)           | 1       |
| `fillet_radius`          | Fillet on top and bottom outer edges (mm)                      | 0.5     |
| `knurl_size`             | Diamond pitch — diagonal of each bump on the rim (mm)          | 2       |
| `knurl_depth`            | Radial height of each diamond bump (mm)                        | 0.6     |
| `cutout_diameter`        | "Circle + plus" circle diameter (mm)                           | 12      |
| `cross_extension`        | How far each "+" arm reaches past the circle rim (mm)          | 1.5     |
| `cross_width`            | Width of each "+" arm (mm)                                     | 2       |
| `bottom_pocket_diameter` | Diameter of the wider bore at the underside (mm)               | 15      |
| `bottom_pocket_depth`    | How far the wider bore extends up from the bottom (mm)         | 4.8     |

## Print

- PLA or PETG, 3 walls, 15% infill.
- Print with the top cap face-down so the "+" and bottom pocket are all upward-opening cavities and need no supports.
