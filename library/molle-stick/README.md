# Molle stick

By [BigFootPL](https://www.printables.com/@BigFootPL) on [Printables](https://www.printables.com/model/411201-molle-stick), Creative Commons — Attribution (CC-BY).

Molle sticks can be used to attach first aid pouches or other accessories that can then be quickly released by pulling on the cord.

String hole fits standard paracord.

Provided in lengths of 3, 4, 5, 6 and 7 inches (one molle strap/gap is 1 inch)

Instructions:

Any material should work. Tested on PLA and PET-G

For symetrical use, model can be mirrored.
